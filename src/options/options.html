GitHub

Creating the token

  1. Open github.com/settings/personal-access-tokens/new.
  2. Resource owner: the account or organization that owns your repos.
  3. Repository access: Only select repositories, and select every repo used in a mapping (or All repositories to avoid updating the token when you add a site).
  4. Repository permissions: Issues: Read and write, Contents: Read and write (for the branch strategy), Metadata: Read (automatic).

A fine-grained token belongs to a single account or organization. Mappings whose owner override points elsewhere can't be reached with the same token; Test reports them as "no access".

Site mappings

One repo per website. example.com matches example.com and www.example.com only; *.example.com also matches every subdomain. A pattern with a port only matches that port. The most specific pattern wins.
